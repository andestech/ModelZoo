# TinyLLama2-110M

## Model infomation
This folder provides the code needed to reproduce the tinyllama2_110M model.

Use 128-token sequence length for the prefill model.

| Name | Task | Source | FP32 | W8A8 qmode-2 Partial-int16 |
| ---- | ---- | ---- | ---- | ---- |
| TinyLLama2-110M | Causal Language Modeling | https://huggingface.co/nickypro/tinyllama-110M | https://huggingface.co/nickypro/tinyllama-110M/tree/main | Model/prefill_128/model.tflite Model/decode/model.tflite |

| Precision Mode | Format | Metric (PPL) | NN SDK Version |
| ---- | ---- | ---- | ---- |
| FP32 | Torch module | 2.14 | N/A |
| Optimized W8A8 qmode-2 Partial-int16 | TFLite v2.17.0 | 2.26 | v1.2.0 |

After the NNPilot flow, the TFLite models prefill_128/model.tflite and decode/model.tflite are generated. Users can use the provided Python script to rearrange the V-cache layout in the TFLite models for better performance.
```
#Model package generated by main_backend.py
SRC=tinyllama2_110M_qmode2

# Output vmove package
OUT=tinyllama2_110M_qmode2_vmove

# Copy other config file from src
mkdir -p "$OUT"
cp -a "$SRC"/. "$OUT"/

# Patch decode and prefill TFLite graphs.
VMOVE_SRC_ROOT="$PWD/$SRC" VMOVE_OUT_ROOT="$PWD/$OUT" \
python ModelZoo/TinyLLama2-110M/scripts/modify_v.py

VMOVE_SRC_ROOT="$PWD/$SRC" VMOVE_OUT_ROOT="$PWD/$OUT" \
python ModelZoo/TinyLLama2-110M/scripts/modify_v_prefill.py
```

## Dataset build


Prepare dataset based on https://github.com/karpathy/llama2.c

```
python tinystories.py download
python tinystories.py pretokenize
```

The folder structure like following:
```
/your_path/tinystories/TinyStories_all_data/
|-- data00.bin
|-- data00.json
|-- data01.bin
|-- data01.json
|-- data02.bin
|-- data02.json
|-- data03.bin
|-- data03.json
|-- data04.bin
|-- data04.json
|-- data05.bin
|-- data05.json
|-- data06.bin
|-- data06.json
```

Change "DATA_CACHE_DIR" to download path in tinystories.py.
```
DATA_CACHE_DIR = "/your_path/tinystories/"
```

The dataset setting is done.
